네 저장소의 코드를 한 줄씩.

키보드 소리로 한글 입력을 알아내는 KDAA 파이프라인의 코드를 처음부터 끝까지 설명합니다. 파이썬 기초 문법(변수, if, for, 함수, 리스트, 딕셔너리)만 알면 읽을 수 있게 썼습니다. 원리는 이 페이지에서 짧게 보고, 나머지는 코드 옆에 붙은 설명으로 익힙니다.

코드 기준 · kdaa-full-sample faf2c4d · sound-autodaq c0823bd · meligation 7acb1bd · classism 386d918

  • kdaa나머지 셋을 순서대로 실행하는 자동화875줄

이 안내서 쓰는 법

  1. 아래 원리 5분을 읽습니다. 프로그램이 무엇을 하는지 감을 잡는 정도면 됩니다.
  2. 코드 읽기 전 파이썬을 훑어봅니다. 다 외울 필요는 없고, 무엇이 있는지만 봐 두세요.
  3. 파일 목록에서 저장소 하나를 골라 위에서부터 읽습니다. 처음이라면 kdaa → meligation → classism → sound-autodaq 순서를 권합니다. kdaa가 가장 짧고 나머지 셋을 어떻게 부르는지 보여 주기 때문입니다.
  4. 코드 페이지는 왼쪽이 코드, 오른쪽이 설명입니다. 설명 속 밑줄 단어는 파이썬 개념 설명으로 갑니다.
  5. 형식과 설정 값을 찾을 때는 참조를 봅니다.

오른쪽 위 검색창(/)으로 함수 이름이나 낱말을 찾으면 그 설명이 있는 줄로 바로 갑니다.

원리 5분

무엇을 하나

키보드는 키마다 위치와 구조가 조금씩 달라서 누를 때 나는 소리도 조금씩 다릅니다. 그 차이를 학습한 프로그램에게 타건 소리를 들려주면 어떤 키였는지 추측할 수 있습니다. 이걸 "음향 사이드채널 공격"이라고 하고, KDAA는 이를 한글 두벌식 자판에 적용하는 연구입니다.

소리를 그림으로

소리 파일은 1초에 48,000개의 숫자(진폭)입니다. 이대로는 키를 구별하기 어려워서, 타건 순간 앞뒤 0.1초만 잘라 "시간마다 어느 높이의 소리가 얼마나 센가"를 표로 만듭니다. 세로 64칸(소리 높이, mel 대역) × 가로 48칸(시간)짜리 표이고, 이것을 로그멜이라고 부릅니다. 흑백 그림 한 장이라고 생각하면 됩니다.

그림을 기호로

CNN(합성곱 신경망)은 그림에서 무늬를 찾는 데 강한 모델입니다. 로그멜 그림을 넣으면 38개 기호(자모 33개 + Space, Backspace, Shift, CapsLock, 기타) 각각에 점수를 매기고, 이를 확률로 바꿔 상위 5개를 내놓습니다. "ㄱ일 확률 72%, ㄷ 16%, …"처럼요. 이 후보들로 문장을 복원하는 일은 다른 팀의 LM 서버가 맡고, 이 네 저장소에는 없습니다.

학습하려면

모델이 배우려면 "이 소리는 ㄱ이었다"는 정답이 붙은 소리가 많이 필요합니다. 그래서 sound-autodaq가 화면에 "ㄱ을 누르세요"를 띄우고, 누른 키를 키보드 훅으로 확인하고, 그 순간의 소리를 저장합니다. 이렇게 모은 수만 개의 소리를 meligation이 로그멜로 바꾸고, classism이 그걸로 모델을 학습합니다. kdaa는 이 과정을 명령 하나로 이어 줍니다.

꼭 기억할 두 가지

  • 학습 때와 실제 사용 때 로그멜을 똑같이 만들어야 합니다. 조금만 달라도 에러 없이 정확도만 떨어집니다. 그래서 만드는 방법(파라미터)을 해시라는 짧은 지문(915acee6)으로 만들어 서로 확인합니다.
  • 세션 단위로 나눠서 시험합니다. 같은 녹음 세션의 소리를 학습과 시험에 섞으면 그 방의 소음까지 외워서 성적이 부풀려집니다.

준비와 첫 실행

아래 명령을 터미널에 차례로 입력합니다. Windows라면 PowerShell에서 하고, 주석(# 뒤)에 Windows용 명령을 적었습니다.

bash
git clone --recurse-submodules https://github.com/regx64/kdaa-full-sample
cd kdaa-full-sample
python -m venv .venv                 # 이 프로젝트 전용 파이썬 환경 만들기
source .venv/bin/activate            # Windows: .venv\Scripts\activate
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt
python -m pytest -q                  # 테스트 10개. "10 passed"가 나오면 준비 끝 (약 1분)

--recurse-submodules는 나머지 세 저장소를 third_party/ 아래에 함께 받으라는 뜻입니다. 빠뜨렸다면 git submodule update --init를 실행하세요. 마지막 테스트 중 tests/test_e2e.py는 가짜 녹음 세션 3개를 만들어 녹음부터 리포트까지 전부 돌려 봅니다.

bash
python -m pytest -q tests/test_e2e.py --basetemp=./tmp-e2e   # 결과 파일을 tmp-e2e에 남겨 열어 보기
python -m kdaa status            # 실제 데이터가 있으면 세션별 상태

먼저 알아 둘 낱말

세션 (session)
녹음 한 번. 참가자·시나리오·세션 번호로 이름이 붙습니다(예: P01_S01_SESSION01).
trial
"이 키를 한 번 누르세요" 한 번. 성공하면 WAV 파일 하나가 생깁니다.
clip_id
학습 데이터에서 타건 하나의 이름. 세션이름_trial번호8자리.
onset
타건이 시작된 순간. 여기서 앞 5 ms, 뒤 95 ms를 잘라 씁니다.
로그멜 (log-mel)
소리 0.1초를 64×48 숫자 표로 바꾼 것.
param_hash
로그멜 만드는 방법의 지문. 다르면 학습을 거부합니다.
shard
세션 하나의 로그멜을 모두 담은 .npz 파일 하나.
epoch
학습 데이터 전체를 한 번 훑는 것.
top-5 정확도
정답이 확률 상위 5개 안에 든 비율.
