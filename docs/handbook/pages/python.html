파이썬

코드를 읽기 전에 알아 둘 파이썬

변수, if, for, 함수, 리스트와 딕셔너리를 안다면 이 페이지의 내용만 더 알면 됩니다. 이 코드에 실제로 나오는 것만 골랐고, 코드 설명에서 처음 나올 때마다 여기로 연결됩니다. 처음부터 다 외울 필요는 없습니다. 코드를 읽다가 모르는 게 나오면 돌아와서 보세요.

파일과 실행

모듈과 패키지import · from . import

파이썬 파일 하나가 모듈, 모듈을 모아 둔 폴더가 패키지입니다. 폴더 안에 __init__.py가 있으면 패키지로 취급됩니다. import json은 표준 모듈을 불러오고, from .pack import pack_session의 점(.)은 "같은 패키지 안의 pack 모듈"이라는 뜻입니다(상대 import).

from . import labels                 # 같은 패키지의 labels.py
from .melio import REGIME, load_clip  # melio.py 안의 두 이름만
import numpy as np                    # numpy를 np라는 짧은 이름으로

상대 import를 쓰는 파일은 python 파일.py로 직접 실행할 수 없고, python -m 패키지.모듈로 실행해야 합니다. 그래서 이 코드의 명령은 모두 python -m kdaa, python -m src.train처럼 생겼습니다. -m kdaa처럼 패키지 이름만 주면 그 안의 __main__.py가 실행됩니다.

스크립트 진입점if __name__ == "__main__"

파일이 직접 실행될 때만 __name__ 변수가 "__main__"이 됩니다. 다른 파일이 import할 때는 모듈 이름이 됩니다. 그래서 이 줄 아래 코드는 "명령으로 실행했을 때만" 돕니다.

def main(argv=None):
    ...
    return 0

if __name__ == "__main__":
    sys.exit(main())     # main이 돌려준 숫자를 프로그램 종료 코드로

sys.exit(n)은 프로그램을 끝내면서 종료 코드 n을 남깁니다. 0은 성공, 그 밖의 숫자는 실패라는 관례입니다. 실제로는 SystemExit 예외를 일으키는 것이라서, raise SystemExit(1)로 써도 같습니다.

from __future__ import annotations파일 첫 줄의 주문

거의 모든 파일 첫머리에 있습니다. 타입 힌트(아래)를 실행할 때 계산하지 말고 글자로만 보관하라는 뜻입니다. 덕분에 str | None 같은 새 표기를 오래된 파이썬에서도 쓸 수 있고, 아직 정의되지 않은 클래스 이름을 힌트에 쓸 수 있습니다. 동작에는 영향이 없으니 보이면 넘어가면 됩니다.

독스트링"""설명"""

파일, 함수, 클래스의 첫 줄에 오는 문자열은 실행되지 않는 설명문입니다. 따옴표 세 개(""")로 여러 줄을 쓸 수 있습니다. 이 코드베이스는 독스트링에 "이 모듈이 맡는 일", 스펙 번호(REQ-57, FR-6 같은 요구사항 번호)를 적어 둡니다.

문법

타입 힌트x: int · -> str · str | None

변수나 인자 뒤의 : 타입, 함수 뒤의 -> 타입은 "이런 값이 오가야 한다"는 메모입니다. 파이썬은 이걸 검사하지 않습니다. 읽는 사람과 편집기를 위한 것입니다.

def load(path: Path, limit: int | None = None) -> list[str]:
    ...
# path는 Path, limit는 정수 또는 None(기본 None), 돌려주는 값은 문자열 리스트

dict[str, int]          # 키가 문자열, 값이 정수인 딕셔너리
tuple[int, int, int]    # 정수 세 개짜리 튜플
Optional[str]           # str | None 과 같은 뜻 (옛 표기)
Callable[[int], str]    # 정수를 받아 문자열을 돌려주는 함수

f-문자열과 서식f"{x:.3f}"

문자열 앞에 f를 붙이면 중괄호 안의 식이 값으로 바뀝니다. 콜론 뒤는 서식입니다.

n, r = 7, 0.0123
f"{n:08d}"     # '00000007'  8자리, 앞을 0으로 채움 (trial_id, clip_id에 씀)
f"{r:.3f}"     # '0.012'     소수 3자리
f"{r:.1%}"     # '1.2%'      백분율, 소수 1자리
f"{n:>5}"      # '    7'     5칸 오른쪽 정렬
f"{'ㄱ'!r}"    # "'ㄱ'"      !r 은 repr(), 따옴표까지 보여 줌 (오류 메시지에 자주 씀)

컴프리헨션[x for x in ...]

for 문으로 리스트를 만드는 것을 한 줄로 줄인 표기입니다. 대괄호면 리스트, 중괄호에 키: 값이면 딕셔너리, 중괄호에 값만이면 집합(set)입니다.

ids  = [s.clip_id for s in samples]                 # 리스트
pos  = {c: i for i, c in enumerate(ids)}            # 딕셔너리: clip_id -> 위치
sess = {s.session_id for s in samples}              # 집합: 중복 제거
kept = [s for s in samples if s.clip_id in store]   # 조건에 맞는 것만
total = sum(1 for _ in reader)                      # 괄호면 '제너레이터': 하나씩 만들며 바로 소비
any(x > 0 for x in xs)                              # 하나라도 참이면 True
all(p.exists() for p in paths)                      # 전부 참이면 True

변수 이름 _는 "값을 쓰지 않는다"는 관례입니다.

풀어 쓰기a, b = … · *rest · **d

rows, ok, skipped = build_session(...)   # 튜플 세 개를 세 변수에
first, *rest = [1, 2, 3]                 # first=1, rest=[2, 3]
merged = {**base, "data": data}          # base 딕셔너리를 복사하고 data 키만 덮어씀
cmd = [python, "-m", m, *args]           # args 리스트의 원소를 그 자리에 펼침
f(*args, **kwargs)                       # 리스트를 위치 인자로, 딕셔너리를 이름 인자로 펼쳐 전달

#                        ^ 이 별표 뒤 인자는 반드시 이름을 붙여 넘겨야 함: Pipeline(cfg, force=True)
def load_samples(root, **options):         # 나머지 이름 인자를 딕셔너리 options로 받음

안쪽 함수와 nonlocal함수 안의 함수

함수 안에서 함수를 정의할 수 있고, 안쪽 함수는 바깥 함수의 변수를 읽을 수 있습니다. 바깥 변수에 새 값을 대입하려면 nonlocal 이름, 모듈 맨 위 변수라면 global 이름을 먼저 선언해야 합니다. 리스트나 딕셔너리처럼 안을 바꾸는 것(append, d[k] = v)은 선언 없이 됩니다.

제너레이터yield

함수 안에 yield가 있으면 그 함수는 값을 한 번에 돌려주지 않고, for 문이 요청할 때마다 하나씩 내줍니다. 큰 데이터를 메모리에 다 올리지 않을 때 씁니다.

def run(self, keystrokes):
    for onset, logmel in keystrokes:
        yield self.push(onset, logmel)   # 하나 처리할 때마다 결과 하나를 내보냄

클래스

클래스와 selfclass · __init__ · super()

클래스는 데이터(속성)와 그 데이터를 다루는 함수(메서드)를 묶은 틀입니다. __init__은 객체를 만들 때 자동으로 불리는 함수이고, 메서드의 첫 인자 self는 "지금 이 객체"입니다.

class Pipeline:
    def __init__(self, cfg):
        self.cfg = cfg               # 객체에 속성 저장
    def run(self):
        return self.cfg["paths"]     # 다른 메서드에서 꺼내 씀

p = Pipeline(cfg)   # __init__(p, cfg) 호출
p.run()             # run(p) 호출

class ShardError(ValueError):        # 상속: ValueError의 성질을 물려받음
    pass

class Dataset(dataset.LogMelDataset):
    def __getitem__(self, i):
        return super().__getitem__(i)   # 부모 클래스의 같은 메서드 호출

이름이 밑줄로 시작하는 속성이나 함수(self._backend, _merge)는 "파일 안에서만 쓰는 것"이라는 관례입니다. 막혀 있지는 않습니다.

특수 메서드__len__ · __getitem__ · __contains__

앞뒤에 밑줄 두 개가 붙은 메서드를 정의하면 파이썬 문법이 그 메서드를 부릅니다.

len(ds)          # ds.__len__()
ds[3]            # ds.__getitem__(3)   PyTorch DataLoader가 이걸로 데이터를 꺼냄

dataclass@dataclass · frozen · field

값을 담는 클래스를 짧게 쓰는 방법입니다. 필드를 나열하면 __init__과 비교, 출력 기능을 자동으로 만들어 줍니다. 이 코드베이스에 40번 넘게 나옵니다.

from dataclasses import dataclass, field, asdict, replace

@dataclass(frozen=True)          # frozen: 만든 뒤 값을 못 바꿈 (규격처럼 고정할 값에 씀)
class Regime:
    sample_rate: int = 48000     # 필드: 이름, 타입, 기본값
    n_mels: int = 64

r = Regime()                     # Regime(sample_rate=48000, n_mels=64)
asdict(r)                        # {'sample_rate': 48000, 'n_mels': 64}
replace(r, n_mels=80)            # 일부만 바꾼 새 객체 (원본은 그대로)

@dataclass
class Session:
    uid: str
    state: dict = field(default_factory=dict)   # 객체마다 새 빈 딕셔너리 (공유 방지)

@property괄호 없이 부르는 메서드

메서드 위에 @property를 붙이면 obj.raw()가 아니라 obj.raw처럼 속성처럼 읽힙니다. 다른 값에서 계산되는 값에 씁니다.

@property
def clip_samples(self) -> int:
    return round((self.pre_ms + self.post_ms) * self.sample_rate / 1000)

r.clip_samples   # 4800  (괄호 없음)

@classmethod, @staticmethod객체 없이 부르는 메서드

@classmethod는 첫 인자로 객체 대신 클래스(cls)를 받습니다. 주로 "다른 형식에서 객체를 만드는" 함수에 씁니다(MelSession.from_npz(path)). @staticmethod는 self도 cls도 받지 않는, 클래스 안에 넣어 둔 일반 함수입니다.

데코레이터@이름

함수나 클래스 위의 @이름은 "아래 것을 이 함수에 넣어서 바꾼 결과로 대신하라"는 뜻입니다. @dataclass, @property도 데코레이터입니다. 이 코드에 나오는 다른 예:

@lru_cache(maxsize=None)       # 같은 인자로 다시 부르면 계산하지 않고 저장된 결과를 돌려줌
def _shard(path, mtime): ...

@register_strategy("random")   # sound-autodaq: 이 함수를 "random"이라는 이름으로 표에 등록
def _strategy_random(...): ...

numpy 배열은 같은 종류의 숫자를 격자로 담은 것입니다. 로그멜 하나는 (64, 48) 배열, 즉 64행 48열의 표입니다. 반복문 없이 배열 전체에 계산을 하므로 빠릅니다.

np.stack([a, b])              # (2, 64, 48)  새 축을 만들어 쌓기
a[None]                       # (1, 64, 48)  앞에 길이 1인 축 추가 (채널 축)

모양이 다른 배열끼리 계산하면 numpy가 길이 1인 축을 자동으로 늘려 맞춥니다(브로드캐스팅). [:, None]은 (n,) 배열을 (n, 1)로 세워 "행마다 다른 값"을 더하거나 곱할 때 씁니다.

np.where(cond, a, b)              # 원소마다 cond가 참이면 a, 아니면 b
np.maximum(0, x)                  # 원소마다 큰 쪽
np.pad(x, 512, mode="reflect")    # 양끝을 거울처럼 512개씩 늘림
np.fft.rfft(frames, axis=1)       # 실수 신호의 푸리에 변환 (주파수 성분)

PyTorch (학습)

텐서torch.Tensor

PyTorch의 텐서는 numpy 배열과 비슷하지만 GPU에서 계산할 수 있고, 계산 과정을 기억해 기울기(gradient)를 자동으로 구합니다. torch.tensor(np_array)로 바꾸고 .to("cuda")로 GPU에 올립니다. 이미지형 입력은 (배치, 채널, 높이, 너비) 순서이고, 이 코드에서는 (B, 1, 64, 48)입니다.

모델 정의nn.Module · forward

class SmallCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.features = nn.Sequential(        # 층을 순서대로 이어 붙인 묶음
            nn.Conv2d(1, 16, 3, padding=1),   # 3×3 필터 16개로 무늬 찾기
            nn.BatchNorm2d(16),               # 값의 범위를 고르게
            nn.ReLU(),                        # 음수를 0으로
            nn.MaxPool2d(2))                  # 가로세로를 절반으로
        self.classifier = nn.Linear(16 * 32 * 24, 38)  # 38개 점수로
    def forward(self, x):                     # model(x) 하면 이 함수가 불림
        return self.classifier(self.features(x).flatten(1))

학습 한 걸음loss · backward · step

model.train()                      # 학습 모드 (Dropout, BatchNorm이 학습용으로 동작)
for x, y in loader:                # DataLoader가 데이터셋에서 batch 크기만큼 묶어 줌
    logits = model(x)              # 예측 점수 (B, 38)
    loss = loss_fn(logits, y)      # 정답 y와 얼마나 다른가 (CrossEntropy)
    opt.zero_grad()                # 이전 기울기 지우기
    loss.backward()                # 기울기 계산
    opt.step()                     # 기울기 방향으로 가중치 조금 고치기

model.eval()                       # 평가 모드
with torch.no_grad():              # 평가할 때는 기울기 계산 안 함 (빠르고 메모리 절약)
    logits = model(x)
torch.save({"state_dict": model.state_dict()}, "best.pt")   # 가중치 저장

한 epoch는 학습 데이터 전체를 한 번 도는 것입니다. 학습률(lr)은 한 걸음의 크기입니다.
